### SEC-001: Security response headers unavailable

Severity: Low. Priority: P3. OWASP A05:2021 Security Misconfiguration.

The production homepage does not return CSP, X-Frame-Options,
X-Content-Type-Options, Referrer-Policy, Permissions-Policy, or HSTS headers.
GitHub Pages does not expose repository-level response-header configuration.
The site has no authentication or server-side processing, which limits impact.
Existing inline event handlers and inline scripts also prevent adopting a
strict CSP without a broader frontend refactor.

Recommendation: retain GitHub Pages with this accepted limitation, or move to
a host that supports controlled headers before treating a strict CSP as a gate.

## Positive Security Controls

- Static architecture with no server-side runtime, authentication, or database.
- HTTPS enforcement is enabled for the custom-domain Pages deployment.
- GitHub secret scanning and push protection are enabled.
- External links opened in new tabs use `rel="noopener"`.
- Generated corpus content is HTML-escaped before rendering.
- Unknown production routes return HTTP 404 rather than a soft-404 redirect.
