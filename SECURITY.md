# Security Policy

## Supported versions

The current `main` branch and the production deployment at
https://VirtualClassroom.watch/ receive security fixes. The project does not
currently publish versioned releases.

## Reporting a vulnerability

Report vulnerabilities privately through the repository's GitHub Security
Advisories page. Do not include secrets, personal data, or exploit details in
a public issue.

Include the affected route or file, impact, reproduction conditions, and any
suggested mitigation. Snap Synapse will acknowledge a complete report as soon
as practical and coordinate disclosure based on severity and reproducibility.

## Scope

The site is a static GitHub Pages reference with a generated JSON API. It has
no authentication, user accounts, server-side data store, or payment flow.
